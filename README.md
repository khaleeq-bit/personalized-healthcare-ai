# 🏥 Personalized Healthcare & Medicine Recommendation System

A machine-learning based healthcare information system that analyzes user-provided age, gender, and symptoms and generates an AI-assisted possible condition prediction.

## 🚀 Features

* 👤 Patient information input
* 🩺 28 symptom selection
* 🤖 Machine-learning based condition prediction
* 💊 General medicine information
* ❤️ Health recommendations
* 📋 Assessment history
* ⚠️ Medical safety disclaimer
* 🌐 Streamlit web interface

## 🧠 Machine Learning

The project uses a **Naive Bayes** classification model.

### Dataset

* 25,000 records
* 30 condition classes
* 28 symptoms
* Age
* Gender
* Symptom count

### Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Jupyter Notebook
* Pickle

## ⚙️ Project Workflow

```text
User Input
    ↓
Symptom Processing
    ↓
Feature Preparation
    ↓
Naive Bayes Model
    ↓
Possible Condition Prediction
    ↓
General Healthcare Information
```

## ▶️ How to Run

Install the required libraries:

```bash
pip install streamlit pandas numpy scikit-learn
```

Run the application:

```bash
streamlit run streamlit_app.py
```

Then open:

```text
http://localhost:8501
```
